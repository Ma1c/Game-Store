# Game Store RESTful API

A full-stack game store application built with **C#**, **React**, and **SQLite**.

The project provides a simple interface for managing games through a RESTful API.

## Tech Stack

- **Backend:** C# / .NET
- **Frontend:** React
- **Database:** SQLite
- **API Architecture:** REST

## Features

- Add a new game
- View the list of games
- Edit an existing game
- Delete a game
- Store game data in an SQLite database
- Manage games through a React-based interface

## Getting Started

### Clone the repository

```bash
git clone <https://github.com/Ma1c/Game-Store/>
```

### Start the backend

```bash
cd GameStore
dotnet run
```

### Start the frontend

```bash
cd GameStore.React
npm install
npm start
```

Make sure that the backend API is running before starting the frontend application.

## Project Purpose

This project was created to practice:

- Building RESTful APIs with C#
- Developing user interfaces with React
- Working with SQLite databases
- Implementing CRUD operations
- Connecting a frontend application to a backend API
